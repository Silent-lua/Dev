# SnowX — By Fabnx1

SnowX main script and avatar modules.

## Files

- `SnowX.lua` — main hub. Automatically downloads and starts the accessory and skin modules.
- `SnowX-Accessories.lua` — accessory and avatar accessory visual system.
- `SnowX-Skins.lua` — skin preview and avatar skin system.

## Run

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Silent-lua/Dev/main/SnowX.lua"))()
```

The main script downloads both modules from the public `main` branch. Keep the two module files at the repository root and preserve their filenames.
